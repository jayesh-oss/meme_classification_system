About The Project

AI-driven platform that analyzes images, extracts text, and classifies memes.

How It Works

The Meme Classification System combines computer vision and natural language processing to understand the visual and textual content of memes. Users upload an image, and the system performs OCR, image analysis, and semantic classification to tag the meme with one or more categories.

Key Features

Text Extraction (OCR)

Extracts embedded text from images using PyTesseract to enable text-based analysis and semantic understanding.

Zero-Shot Classification

Uses CLIP ViT-B/32 to compare the meme image against category prompts, so it can classify without any training data.

Fusion Head

An optional trained head combines CLIP image embeddings with OCR text embeddings for higher accuracy once a labeled dataset is available.

Classification Pipeline

  1. User uploads a meme image via the dashboard UI.
  2. OCR engine processes the image to extract all readable text.
  3. The image is compared against the four category prompts using CLIP.
  4. CLIP assigns confidence scores to our 4 primary categories.
  5. Results, metadata, and history are saved to local storage.
